# Mulu (目录)

*[Leia em português](README.pt-BR.md)*

**Mulu is a free, open-source digital librarian for Windows and macOS.** It finds the books and texts on your computer, reads them, and lets you search inside all of them at once, in a fraction of a second. It works entirely offline.

> **Status: early test version.** Mulu is being designed and built in the open. Version 0.2 is for testers: it indexes one or several folders of books, or the whole computer (PDF, EPUB, plain text, Markdown, HTML), keeps the index up to date by reading only what changed, and searches all of it or only the folders you tick, with signs for exact phrases, alternatives, exclusions and words near each other, taught by an advanced search panel. What comes next is in the [roadmap](ROADMAP.md).

## What Mulu will do

- **Search inside your whole library.** Type a word, a name or an exact phrase and see every book that contains it, with the passages where it appears and the page or chapter.
- **One result per book.** Each file appears once, with the number of times your term appears in it. Open the list to see every passage.
- **Reading notes in one click.** Select passages and export them to a document (Word, LibreOffice, RTF, Markdown or plain text), with author, title, year and page.
- **Read scanned books.** Pages that are only images can be recognized (OCR). Planned languages: Portuguese, Spanish, English, French, German, Italian, Modern and Ancient Greek, Latin, and Simplified and Traditional Chinese. Each language is confirmed only after its recognition quality has been measured and published.
- **Keep your library in order.** Filters by author, year, format and folder; tags; duplicate detection; optional renaming and moving, always with a preview and an undo option.

Supported formats: PDF, EPUB, MOBI and AZW3 (without DRM), DJVU, DOCX, DOC, ODT, RTF, TXT, Markdown, HTML and FB2. Files with DRM are listed as "protected" and never unlocked.

## Promises

- **Private.** No account, no ads, no data collection, no internet connection. An optional update check will be off by default.
- **Safe for your files.** Mulu only reads your books. Anything that renames or moves a file asks first, shows what will change and can be undone. Nothing is ever deleted or overwritten.
- **Simple.** One file to download, two clicks to install, no administrator password, no technical questions.
- **Honest.** Speed and quality are measured and published with every version. What is not finished or not tested is said plainly.
- **Free.** Free software under the [GNU General Public License, version 3 or later](LICENSE). The same complete program will be free on this page and sold in the app stores, where the price buys automatic updates and supports the project. There are no locked features.

## Platforms

Windows is the reference platform. macOS is built from the same code and is labeled "experimental" until it has been tested on a real Mac. Chromebook support is planned after version 1.0.
