**Rehearsal version for testers. It does not search yet.**

This version only opens Mulu's window. It exists to test the whole delivery path before search arrives in 0.1: automatic build, download, installation without administrator rights, and first launch.

- **Windows:** `Mulu_0.0.1_x64-setup.exe`. The installer is not digitally signed yet (decision D11), so Windows will warn before running it.
- **macOS (experimental):** `Mulu_0.0.1_universal.dmg`, for Apple silicon and Intel Macs. It is not signed or notarized by Apple, so macOS will block it until you allow it in System Settings → Privacy & Security. It has not been tested on a real Mac yet.
- **Windows Sandbox file:** `Mulu-v0.0.1-test-sandbox.wsb` opens a disposable copy of Windows with this page, so you can test without touching your computer.
- **Checking the files:** `SHA256SUMS.txt` lists the checksum of every file. A build provenance attestation proves that each file was built by GitHub Actions from this repository: `gh attestation verify <file> --repo miguelbconde/mulu`.

How to test: [docs/testing/v0.0.1.md](https://github.com/miguelbconde/mulu/blob/main/docs/testing/v0.0.1.md).
