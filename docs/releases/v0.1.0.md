**First version that searches. For testers.**

Choose the folder with your books: Mulu finds them, reads them in the background and lets you search every word inside, with the number of occurrences per file and passages with the page or chapter. Works entirely offline.

- **Formats:** PDF, EPUB, plain text, Markdown, HTML. Files protected by DRM or a password, or kept only in the cloud, are listed and can be found by name.
- **Search:** words (all must be in the file), exact phrases between quotes, the beginning of a word with a star (`melancol*`); accents and capitals ignored; text in every script is indexed.
- **Safety:** Mulu only reads your files. Each file is read in a separate, low-priority process with time and memory limits.
- **Windows:** `Mulu_0.1.0_x64-setup.exe`. Not digitally signed yet (decision D11): Windows will warn before running it.
- **macOS (experimental):** `Mulu_0.1.0_universal.dmg`, not signed or notarized by Apple yet; not tested on a real Mac yet.
- **Checking the files:** `SHA256SUMS.txt`, and a build provenance attestation: `gh attestation verify <file> --repo miguelbconde/mulu`.

How to test: [docs/testing/v0.1.0.md](https://github.com/miguelbconde/mulu/blob/main/docs/testing/v0.1.0.md). Changes: [CHANGELOG.md](https://github.com/miguelbconde/mulu/blob/main/CHANGELOG.md).

**Primeira versão que pesquisa. Para testadores.** Escolha a pasta dos seus livros: o Mulu os encontra, lê em segundo plano e permite pesquisar cada palavra, com o número de ocorrências por arquivo e trechos com a página ou o capítulo. Funciona inteiramente sem internet. O instalador do Windows ainda não tem assinatura digital, então o Windows vai mostrar um aviso antes de executá-lo. O roteiro de teste está no link acima.
