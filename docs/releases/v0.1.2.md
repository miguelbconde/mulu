**New PDF engine. For testers.**

PDFs are now read with PDFium, Google's PDF engine (the one in Chrome), instead of pdf_oxide. On real books it was 20 to 190 times faster in our measurements, with far less memory, for the same text quality; large books no longer hit the time limit. It runs only in Mulu's separate reading process, whose memory is now also watched from outside.

Windows: `Mulu_0.1.2_x64-setup.exe` (not digitally signed yet: Windows warns before running it). macOS (experimental, not yet tested on a real Mac): `Mulu_0.1.2_universal.dmg`. Test script: [docs/testing/v0.1.2.md](https://github.com/miguelbconde/mulu/blob/main/docs/testing/v0.1.2.md).
