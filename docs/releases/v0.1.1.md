**Corrections after the first test. For testers.**

- "Show in folder" now opens the file's own folder on Windows.
- Lists and help close from a × at the top, or with Esc.
- Faster reading: several files are read at the same time.
- Files that could not be read are grouped by reason; a reading report can be copied and sent to the developer.

Windows: `Mulu_0.1.1_x64-setup.exe` (not digitally signed yet: Windows warns before running it). macOS (experimental): `Mulu_0.1.1_universal.dmg`. Test script: [docs/testing/v0.1.1.md](https://github.com/miguelbconde/mulu/blob/main/docs/testing/v0.1.1.md).
