**Long books read in full, and a better "Read faster". For testers.**

- Long books are no longer stopped after two minutes while they advance: only a file that stops advancing is stopped.
- "Read faster" uses one reading per physical processor core, and the largest files are read first.
- The reading report says how many files were read at once.

Windows: `Mulu_0.1.4_x64-setup.exe` (not digitally signed yet). macOS (experimental): `Mulu_0.1.4_universal.dmg`. Test script: [docs/testing/v0.1.4.md](https://github.com/miguelbconde/mulu/blob/main/docs/testing/v0.1.4.md).
