**Only what changed is read again, and the search can leave folders out. For testers.**

- Each time Mulu opens, and with the new ↻ button, it checks the library and reads only new and changed files. Renamed and moved books keep their place in the index; files no longer in the folder leave the index (never the disk).
- A panel on the left shows the library, the date of the latest check and what it found, and the library's folders with checkboxes: unticked folders are left out of the search, instantly.
- Updating from 0.1 keeps the index: install over the previous version.

Windows: `Mulu_0.2.0_x64-setup.exe` (not digitally signed yet). macOS (experimental): `Mulu_0.2.0_universal.dmg`. Test script: [docs/testing/v0.2.0.md](https://github.com/miguelbconde/mulu/blob/main/docs/testing/v0.2.0.md).
