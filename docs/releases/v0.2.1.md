**Several libraries, a count before reading, and "whole computer". For testers.**

- Add as many libraries as you like with "+ Add a library"; a search covers them all, and each result says which library it comes from. A library can be taken out of Mulu without touching its files.
- Before the first reading, Mulu counts the books by format and by folder, so you can leave out what you do not want read.
- "Whole computer" reads your home folder and your other disks, leaving out system, program, hidden and temporary folders.
- Includes everything in 0.2.0: only what changed is read again, and the search can leave folders out.

Windows: `Mulu_0.2.1_x64-setup.exe` (not digitally signed yet). macOS (experimental): `Mulu_0.2.1_universal.dmg`. Test script: [docs/testing/v0.2.1.md](https://github.com/miguelbconde/mulu/blob/main/docs/testing/v0.2.1.md).
