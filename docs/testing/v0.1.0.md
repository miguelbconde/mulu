# Test script: version 0.1.0 (first version that searches)

This version finds, reads and searches the books of one folder. Test it in a **separate Windows account** with a **copy** of your library (decision D19, [test-account.md](test-account.md)), so that a defect can only reach the copy. Please write down every warning, the times, and anything that looks wrong; screenshots help a lot.

## Windows

### A. Install (in the test account)

1. Sign in to the test account (for the maintainer: **Mulu Teste**).
2. If version 0.0.1 is installed there, uninstall it first: **Settings → Apps → Installed apps → Mulu → Uninstall**.
3. Open https://github.com/miguelbconde/mulu/releases/tag/v0.1.0 in Microsoft Edge. Start a stopwatch and download `Mulu_0.1.0_x64-setup.exe`.
4. If the browser warns about the download, note the text and choose to keep the file.
5. Open it. Windows will probably show **"Windows protected your PC"** (the installer is not signed yet, D11): note the text, click **More info**, then **Run anyway**.
6. The installer must not ask for an administrator password. Stop the stopwatch when Mulu's window appears; note the time and the number of clicks.

### B. First launch and indexing

1. The window shows a single button, **Choose the folder with your books**, and **Version 0.1.0** at the bottom. Note the interface language.
2. Click the button and choose the copy of your library (for the maintainer: **Public Documents → Biblioteca de teste do Mulu**). Start a stopwatch.
3. A progress bar shows "Reading the books: N of total". Note the total.
4. While it runs, use the computer normally for a minute (open a document, a web page): note whether it feels slow.
5. While it runs, search for a word: results must already appear for the books read so far.
6. Halfway, **close Mulu** and open it again from the Start menu: indexing must continue where it stopped, not start over.
7. Stop the stopwatch when the progress bar disappears and the line says "N files in the library". Note the time and N.
8. If a red line says "N files could not be read", click it and note the reasons shown (copy a few examples).

### C. Searching

Try these, and anything you usually look for. For each, note whether the results look right and complete.

1. A word you know is in many books (e.g. `melancolia`). Files must come with the most occurrences first, each with its count.
2. The same word with different accents or capitals (`MELANCOLIA`, `melancolía`): the same results.
3. An exact phrase between quotes (e.g. `"olhos de ressaca"`).
4. The beginning of a word with a star (`melancol*`): melancolia, melancólico, melancholy…
5. Two words without quotes (e.g. `capitu ressaca`): files that contain both, anywhere.
6. An author's surname that appears only in file names: the file must appear under **Found by the file name**.
7. If your library has Greek, Russian, Chinese or other scripts, a word in that script.
8. Open the passages of a file (the arrow): 25 words before and after, the term in yellow, and the page (or chapter for EPUB). Check one page number against the book. Click **Show more** if there are more than ten.
9. **Double-click** a file (or select it with Tab and press Enter): it must open in your usual program. Click **Show in folder**: Explorer must open with the file selected.
10. Press **Ctrl+F**: the cursor goes back to the search box.
11. Click **?**: the help opens; check that it is understandable.

### D. Uninstall

**Settings → Apps → Installed apps → Mulu → Uninstall.** Note whether anything asks for a password. Then go back to your own account.

## What to send

- Windows version (**Settings → System → About**, e.g. Windows 11 Pro 24H2).
- Every warning, with its exact text (a photo of the screen is fine).
- Times: download to first window (and clicks); indexing of the whole library; number of files.
- Whether the computer felt slow during indexing.
- Reasons in the "could not be read" list, with a few file names.
- Searches that gave wrong, missing or surprising results.
- Anything else that looked strange.

## Known limits of 0.1

- One library folder only; several libraries, the whole computer, and choosing which subfolders to search come in 0.2.
- Changes in the folder after indexing (new, changed, deleted files): new files are found when Mulu opens; changed and deleted files are handled in 0.2.
- Formats: PDF, EPUB, plain text, Markdown, HTML. DOCX, ODT, RTF, MOBI, DJVU and others in 0.4; scanned pages (OCR) in 0.5.
- Hebrew and Arabic text from some PDFs comes out reversed (D24); fixed in 0.8.
- Opening a file at the page found comes in 0.3.

## macOS (experimental)

Download `Mulu_0.1.0_universal.dmg`, open it and drag Mulu to Applications. The app is not signed by Apple yet: the first time, macOS blocks it; allow it in **System Settings → Privacy & Security → Open Anyway**. macOS will ask for permission when Mulu reads a folder such as Documents. Then follow parts B and C.
