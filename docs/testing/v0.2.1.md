# Test script: version 0.2.1

In the test account. Install over the version you have (0.1.4 or 0.2.0): do not uninstall it. Version 0.2.1 includes everything in 0.2.0.

1. **Update.** Install `Mulu_0.2.1_x64-setup.exe` from https://github.com/miguelbconde/mulu/releases/tag/v0.2.1 and open Mulu. Note how long it takes until the panel on the left says "Checked on …", and what the line below says (expected: "No changes since the last check").
2. **Same search.** Search `homero`: expected 8,268 occurrences in 574 files.
3. **Scope.** Open a folder of the tree with its arrow, untick a folder that has results (they leave at once; the summary says "in part of the library"), tick it again.
4. **Changes.** In File Explorer, in the test library: copy a book from elsewhere into a folder; move another book out (to the Desktop). Click ↻: expected "1 new, 1 removed from the index". Then rename the book you added and move it to another folder; click ↻: expected "1 renamed or moved".
5. **A second library, with the count before reading.** Click "+ Add a library" and choose another folder with a few books (for example a copy of a course folder in Public Documents). A window lists the books by format and by folder: untick one folder, then "Read these books". Search a word in both libraries: each result says its library.
6. **Refusal.** Click "+ Add a library" and choose a subfolder of the test library: expected a message saying it is already part of that library.
7. **Taking a library out.** Under the second library, click "Take out of Mulu" and confirm. Its folder and files must still be there.
8. **Whole computer (look only).** Click "or the whole computer": note how long "Counting the books…" takes and what places it lists. Click "Cancel".
9. Note any warning from Windows.
