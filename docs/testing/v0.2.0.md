# Test script: version 0.2.0

In the test account. This time, do **not** uninstall 0.1.4: installing over it checks that an update keeps the index.

1. **Update.** Install `Mulu_0.2.0_x64-setup.exe` from https://github.com/miguelbconde/mulu/releases/tag/v0.2.0 over 0.1.4 and open Mulu. Note how long it takes until the panel on the left says "Checked on …" (it should be seconds, not the 20 minutes of a first reading) and what the line below it says (expected: "No changes since the last check").
2. **Same search.** Search `homero`: expected 8,268 occurrences in 574 files, as in 0.1.4.
3. **Scope.** Open a folder in the tree with its arrow. Untick a folder that has results: they leave the list at once, and the summary says "in part of the library". Tick it again: they come back. Click the box of the library itself, then click it again.
4. **New, changed and removed files.** In File Explorer, in the test library: copy a book from elsewhere into a folder; move another book out of the library (for example to the Desktop). Click ↻. Expected: "1 new, 1 removed from the index", and the new book is found by a word from its text.
5. **Renamed and moved.** Rename the book you added in step 4 and move it to another folder of the library. Click ↻. Expected: "1 renamed or moved", found at its new place. (Books read by 0.1.4 have no fingerprint yet: if one of those is renamed, it is read again, which is expected.)
6. Note any warning from Windows.
