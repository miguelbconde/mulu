# Test script: version 0.1.4

1. In the test account, uninstall the previous version ticking **Delete the application data**, then install `Mulu_0.1.4_x64-setup.exe` from https://github.com/miguelbconde/mulu/releases/tag/v0.1.4.
2. Choose the same folder and click **Read faster** right away. Note the start and end times. At first the counter moves slowly (the largest books come first); it speeds up later.
3. Open the list of files that could not be read: the "took too long" group should be empty (Freud's complete works and Kalkavage's Hegel are read). Copy the reading report into your message.
4. Search `homero` and compare with 0.1.3 (8,257 occurrences in 573 files).
