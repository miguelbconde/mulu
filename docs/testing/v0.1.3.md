# Test script: version 0.1.3

1. In the test account, uninstall the previous version ticking **Delete the application data**, then install `Mulu_0.1.3_x64-setup.exe` from https://github.com/miguelbconde/mulu/releases/tag/v0.1.3.
2. Choose the same folder. After a minute, click **Read faster**: note whether the reading speeds up and whether the computer becomes slow. Click **Back to background reading** for a minute, then **Read faster** again until the end. Note the total time.
3. Open the list of files that could not be read: the "too large" group should be gone or much smaller. Copy the reading report into your message.
4. Search `homero` and compare with 0.1.2 (7,951 occurrences in 565 files).
5. In the list, under **damaged file**, pick one file that opens normally in your PDF reader, and send it (only if you are comfortable sharing it).
