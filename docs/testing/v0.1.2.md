# Test script: version 0.1.2

New PDF engine (D28). Same test account and library copy as before.

1. In the test account, download `Mulu_0.1.2_x64-setup.exe` from https://github.com/miguelbconde/mulu/releases/tag/v0.1.2. Uninstall the previous version, ticking **Delete the application data** (only Mulu's index; never your books), then install 0.1.2. Note any warning.
2. Choose the same folder and time the reading from start to end. Note whether the computer felt slow.
3. Search for the same word as before (e.g. `homero`): note the number of occurrences and files, and compare with 0.1.1 (8,052 in 576 files). A few more or fewer is expected: the new engine reads some pages differently. Open a few passages and check that the text reads well and the page numbers are right.
4. Open the list of files that could not be read and copy the reading report into your message.
5. Double-click a PDF to open it, and click **Show in folder** once.
