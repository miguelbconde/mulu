# Test script: version 0.0.1 (rehearsal)

This version only opens a window. The goal is to test the delivery path: download, install without administrator rights, first launch, uninstall. Please write down every warning you see, on which system, and how long each part took.

## Windows

You need Windows 10 or 11, Pro or Enterprise edition, for Windows Sandbox. On Home editions, skip part A and install directly (part B).

### A. One-time setup: turn on Windows Sandbox

1. Press the Windows key, type **Turn Windows features on or off**, and open it.
2. Tick **Windows Sandbox**, click **OK**, and restart the computer when asked.

### B. Test

1. Open the release page: https://github.com/miguelbconde/mulu/releases/tag/v0.0.1
2. Download `Mulu-v0.0.1-test-sandbox.wsb` and double-click it. A clean, disposable Windows opens in a window, already showing the release page. Everything below happens **inside that window**.
3. Start a stopwatch. Download `Mulu_0.0.1_x64-setup.exe`.
4. Note any warning from the browser about the download. If it offers to keep or discard the file, choose to keep it.
5. Open the file. Windows will probably show **"Windows protected your PC"**. Click **More info**, then **Run anyway**. Note the exact text.
6. The installer should not ask for an administrator password. Follow it with the fewest clicks possible. Stop the stopwatch when Mulu's window appears. Note the time and the number of clicks since step 3.
7. Check the window: the title **Mulu**, the red 目录 seal, the text in your system language, the grey button "Choose the folder with your books" that cannot be clicked yet, and **Version 0.0.1** at the bottom.
8. Make the window smaller and larger; the header and the footer should stay in place.
9. Close Mulu and open it again from the Start menu.
10. Uninstall it: Settings → Apps → Installed apps → Mulu → Uninstall. Note whether anything asked for a password.
11. Close the sandbox window. Everything inside it is erased.

## macOS (volunteers)

1. Download `Mulu_0.0.1_universal.dmg` from the release page and open it.
2. Drag Mulu to Applications, then open it. macOS will refuse, because the app is not notarized yet.
3. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to the message about Mulu. Note the exact messages.
4. Check the window as in Windows step 7.
5. To remove it, drag Mulu from Applications to the Trash.

## What to report

- System and version (for example, Windows 11 Pro 24H2).
- Every warning, with its exact text.
- Time and number of clicks from download to the first window.
- Anything that looked wrong, with a screenshot if possible.
